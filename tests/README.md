# 定向验收脚本

日常回归使用 `pnpm build && pnpm test`。几何套件覆盖分区占比、固定设施、设备缺失、椅背净距与项目读写。生产版浏览器套件覆盖试排、应用、另存、刷新和 PNG 入口标记。它也通过鼠标切换 3D 光照，走完选墙、输入净距、预览、确认和撤销，并在整场地与独立规划范围间核对底栏冲突数和体检明细。

基础草稿用例随上述命令一起运行。只读离屏渲染用例（`offscreen-render.mjs`）对比示范案例在实时视图与离屏 3D/2D 渲染的 PNG 尺寸与非空白像素比例，校验拍摄其他方案时不改动活动项目、撤销栈、选区与 IndexedDB `updatedAt`，并覆盖底图资产缺失、隐藏与正常加载。快速出图用例从空白画布修改 L 形预设，检查首稿默认暖调风格、实际 PNG 尺寸、系统剪贴板的图片类型、导出弹窗内一键切风格自动重拍合图/鸟瞰、更换地材时刷新平面与一次撤销恢复、无同铺提示直达「比较摆法」、同铺 A/B 双方案 2400×1500 对比图预览/复制/下载及状态与 IndexedDB 隔离、单图切换和退出后的工作视图。几何部分覆盖单圈直角铺形、镜像和旋转、固定隔间阻断入口、小档口降级、60 米大铺、同铺判定（同铺/镜像/同面积异形/入口移动/固定构件移动）与 A/B 指标计算、业态默认风格与旧项目缺省样式回读，以及拖拽局部净距计算（桌组/实测内墙/重叠/超距过滤与 300 物件耗时基准）。浏览器从默认格网画出 L 形铺位并标入口和柱，核对桌组拖动时实时通道净距标尺与警示态、松手消失及撤销还原、单椅删除、撤销和重做、保存刷新、平面 PNG 与 3D PNG、同铺候选的预览、原地应用与撤销、另存后重开手改原稿，以及项目包回读。按尺寸建铺还验证矩形、四向 L 形、非法缺口修正及带入口生成。

历史专项从仓库根目录运行 `pnpm typecheck` 和 `pnpm build`，再按改动选择下方的浏览器流程。浏览器脚本复用已有 Playwright 与本机 Chrome，命令中的路径指向 Playwright 包。性能脚本适用于涉及渲染或交互性能的改动。

```text
node tests/g4-workflow.cjs <已有 Playwright 包路径>
node tests/g4-workflow.cjs <已有 Playwright 包路径> linked
```

主流程覆盖组合/阵列、撤销、自由旋转、吸附、关联净距、空间检查、刷新与包导入；`linked` 只补查墙窗组合和旧自由旋转包。使用本地 5192 端口，分别建立隔离浏览器存储，结束时关闭自己启动的浏览器和服务。

`g1-storage.browser.js` 和 `g2-invariants.browser.js` 由 G2 脚本导入，必须在一次性浏览器环境运行，不能在用户日常方案库中注入故障。历史脚本会随功能演进按需维护；修改版本断言或通过语法检查不代表本轮已重新跑完其全部流程。

所有 `.cjs` 的截图、样例和机器结果默认写入 `.local-checks/<阶段>-evidence/`。可用环境变量 `CANTEEN_EVIDENCE_DIR` 指定另一输出目录（相对仓库或绝对路径）。输入旧版本兼容性样例仍读取 `docs/`，不要覆盖这些归档样例来凑通过结果。

历史 Markdown 中“更新截图/JSON”指当时的输出流程；当前默认输出位置以本说明为准。脚本需要空闲端口；使用同一端口的主流程和 `linked` 分开运行。复跑结果不会自动成为新的阶段验收记录。
