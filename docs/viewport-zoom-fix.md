# 缩放跳动与空白区域修复

## 定位证据

- 二维同一帧分发 8 次 deltaY=-50 滚轮事件，理论倍率 2.22554，修复前只有 1.10517：相机更新读取旧渲染状态，后续事件覆盖前面的更新。
- 三维缩远上限为 Infinity，远裁切面固定为 300m；复现时相机距离达到约 59268m，场景被裁掉。
- 二维定位直接使用“视口高度减 120”，极矮分屏产生零或负缩放。
- 特写在窗口尺寸变化时把轨道目标重新设置为物件中心，覆盖用户平移位置。

## 修复

二维采用函数式状态更新累积滚轮输入；在布局阶段更新监听，通过 SVG 矩阵换算屏幕坐标；定位限定正数尺寸和 20%–1200% 缩放范围。

三维设置随场地/特写尺寸变化的缩放上下限，按距离更新近远裁切面，提高缩远时的深度精度。地面覆盖层增加深度偏移，减少共面闪烁；截图相机使用对应距离的近裁切面。特写仅跟随物件的实际位移，窗口调整保留用户平移目标。模型、环境更新和隐藏视图恢复后显式请求渲染。

## 验证

- pnpm build（含 TypeScript 检查）通过，保留既有主包体积提示。
- viewport-zoom.cjs：11 项断言通过。二维倍率 2.225541，指针锚点误差约 0.0035mm；三维连续放大、缩小各 160 次，20m 场地最大观察距离为 240m，远裁切面为 1000m，地面仍在视锥内。
- 覆盖极矮分屏定位、特写窗口调整、反复切换视图、截图后的相机与渲染尺寸恢复。
- free-rotation.cjs：26 项回归断言通过。两组浏览器测试均无未捕获页面异常。
- 使用本机 Chrome 隔离存储；结果与截图在 .local-checks/zoom-evidence/ 和 .local-checks/rotation-evidence/。未覆盖所有显卡驱动或浏览器组合。
