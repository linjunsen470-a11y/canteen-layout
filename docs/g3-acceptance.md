**G3 底图、资产包与独立规划范围：实现与验收**

日期：2026-11-05。用户本轮指定的三项已完成。本次保留原有 2D/3D、项目库、标注、墙窗、功能分区及所有既有未提交修改；不进入云端或其他阶段。这是 G3 首轮历史记录；其余条目现已由后续任务补齐，见 [G3 完成记录](g3-completion.md)。

**可直接使用的流程**

1. 打开“场地资料 / 范围”，展开“现场底图”，导入 PNG/JPEG。
2. 点击“两点校准”，在图片上选两个已知距离的端点，输入毫米距离并应用。第一个端点固定，图片按比例缩放；场地和设备不移动。
3. 底图默认锁定。解锁后可拖动或填写 X/Y/旋转角度；可调整透明度、显隐。Esc 取消拖动，撤销恢复上一个完成的修改。校准是单独的明确操作，不要求解除拖动锁。
4. 用整场地轮廓保留完整地面，再“绘制新规划范围”，逐点点击后闭合。可创建多个名称/颜色不同的范围；调整边界支持拖顶点、点击 + 加点、右键删点。范围需完整位于整场地内，边界不允许自交。
5. 从工作台“规划范围”下拉框切换。当前范围在 2D/3D 高亮，范围外物件可淡化；默认开启范围外保护。物件完整旋转外包必须在范围内才允许编辑，门窗同时遵守所属墙体规则。切回整场地或关闭保护可继续编辑区外物件。
6. 点击“项目包”下载 `.canteen.json`，用“导入”在另一浏览器/电脑恢复。普通 JSON 仅带几何、资料与资产引用，文件内和界面均明确不含图片。

**数据边界**

- 项目格式 3，继续读取未标版本及版本 1/2；未来未知版本拒绝。
- `underlay` 保存资产 ID、像素尺寸、位置、mm/px、角度、透明度、锁定/显隐、校准两点和已知毫米距离。真实图像 Blob 存 IndexedDB assets，不保存临时 blob URL。
- 项目包格式 1：项目文档 + Base64 图片。导入验证图片类型、解码与像素尺寸后写入新资产 ID，再创建独立项目；不会覆盖同名项目或原资产。
- `planningAreas` 保存命名多边形。整场地 `outline`、功能分区 `kind:zone` 与规划范围分别表达不同用途。当前激活范围、保护/淡化开关是编辑会话状态，重开项目回到整场地。范围可重叠，不将其面积累加为场地总面积。
- 轻量上限：一个项目一张底图，PNG/JPEG ≤12MiB、≤3200 万像素；项目导入 ≤20MiB；最多 50 个规划范围，每个 3–64 个顶点。无 ZIP/CAD 解析、图像矫正、自动描图或新应用依赖。
- 旧图片资产暂不自动回收，使替换/移除后的撤销、项目副本及恢复记录仍可用。清理浏览器站点数据会删除本机项目与图片，请使用项目包做外部备份。
- 底图加载未完成或缺失时，平面导出/全景三维截图会提示恢复底图。平面 PNG 保持整场地交付，移除工作范围高亮和编辑淡化；三维截图保留当前可见范围高亮与淡化。
