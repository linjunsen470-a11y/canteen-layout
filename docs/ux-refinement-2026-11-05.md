# 门窗与编辑工作区体验修复

本轮围绕实际布置操作修复误操作和空间占用问题；保留本地项目格式 6、旧独立门窗数据及设备自由旋转行为。

## 已实现

| 问题 | 修改后行为 |
| --- | --- |
| 仅有单开门 | 新增等宽双开门，库条目共 67 项；二维弧线、三维双扇及空间检查共用门扇定义 |
| 门轴与开启侧无法分别设置 | 单开门可选择墙起点/终点侧门轴，开启侧可独立反转；门型、窗型可直接切换，保留尺寸和位置 |
| 旋转贴墙门窗时自动脱墙 | 贴墙角度只读、隐藏旋转柄，状态层同时约束属性、指针及批量路径；独立示意需明确选择“独立放置” |
| 拖入开口时跳到另一处空位 | 按实际落点检查冲突，失败给出原因；点击库条目添加时仍查找最近可用位置 |
| 自动找位漏掉刚好可用的空隙 | 搜索开口前后边界和墙端候选，排除当前对象自身，优先靠近目标位置 |
| 修改墙体绕过关联门窗锁定 | 几何修改前检查关联门窗的锁定、显隐及规划范围保护 |
| 操作区被面板挤压 | 默认二维；侧栏可调宽，工具区可折叠；F 进入专注画布，Esc 恢复原侧栏和视图；恢复不覆盖原偏好 |
| 小屏专注后仍强制换行 | 视图工具条按编辑器容器宽度布局，利用展开后的可用宽度 |
| 无效尺寸静默恢复 | 空值、无效值及越界数值显示具体原因、保留原值；支持小数及 Esc 取消 |
| 场地尺寸埋在次要设置下方 | 形状、长宽和面积前置，底图、规划范围及分区统计放在后面 |

侧栏宽度支持指针、方向键和双击/Home 复位；工具区折叠、宽度与视图偏好可刷新恢复。专注模式为临时状态，刷新回到正常布局。专注状态下生成客户成果会暂时恢复视图供截图，结束后回到专注布局。

## 第二轮：开向可发现性和批量操作

原先“反转开门方向”位于尺寸等属性下方，且没有当前方向反馈。本轮将开向控制移到名称下方，提供二维方向预览、明确的画布方向选项及门轴设置；同一组件支持批量开向设置，保留贴墙方向约束。

对象列表新增复选框、全选搜索结果、取消选择。复制与粘贴使用当前应用会话内的不可变快照；墙体会自动携带关联门窗，新 ID、墙窗引用、完整组合及已复制的承托物/区域/净距标注引用一起映射。单独复制门窗时保留原墙关联，跨项目缺少墙体则整批拒绝。粘贴进入指针放置，Esc 回滚并恢复原选择，落位后一次撤销/重做。剪贴板不跨刷新、不写系统剪贴板。

快捷键：Ctrl/⌘+A 全选可编辑构件，C 复制，V 粘贴，D 快速副本，G 组合，Shift+G 解组；输入框和打开的对话框保留原生键盘操作。工具栏“复制”现在只复制，“副本”保留立即生成副本的功能。

第二轮验证：`pnpm build`（含 TypeScript 检查）通过；`clipboard-doors.cjs` 25 项、`ux-refinement.cjs` 66 项断言通过，均无页面未捕获异常。输出分别位于 `.local-checks/clipboard-evidence/` 和 `.local-checks/ux-evidence/`。
