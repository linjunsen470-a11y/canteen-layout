# G2 编辑状态与工作台体验

日期：2026-11-05。范围仅 G2；沿用 React/Vite/Zustand/SVG/R3F 和现有本地项目库。保留原工作区未提交成果，未连接云端、业务库或上线，也未新增应用依赖。

## 实现

- `store.ts` 集中维护选择集合、主选对象、编辑模式和当前工具。2D、3D、对象列表共用同一选择；切换项目、撤销/重做清理失效选择和临时工具。
- 工作台明确显示设备布置、建筑构件、场地轮廓及当前工具；三维查看通过视图按钮进入。墙/隔断拖线、矩形区域、轮廓绘制提供松开完成、闭合/完成、取消/Esc 提示。
- 左侧可切换设备库和对象列表。对象可按名称或 ID 搜索、选择、Shift 多选、显隐、锁定及定位；薄墙、门窗及重叠对象不必从画布中点中。
- 右侧独立显示场地、单选或批量属性。批量尺寸、朝向和颜色对可编辑对象共同生效；不同值显示为空；锁定或隐藏对象明确跳过。门窗的从属墙厚/方向不作为独立公共属性，尺寸校验失败整批拒绝。
- 显隐和锁定是可撤销、可持久化的对象属性；隐藏墙体会隐藏从属门窗。显隐影响 2D、3D 和 PNG，JSON 保留所有对象；隐藏门窗本身不会改变墙体开口几何。新增门窗不会自动吸附隐藏墙体。
- 拖动取消统一回退事务并释放指针捕获；切换工具、视图和项目不残留拖动。输入框、模态对话框、轮廓 Backspace 与全局 Delete/撤销各自处理，按钮 Space 不再被平移快捷键截走。
- 数值输入后直接拖动物件会先提交数值，再开启拖动；Esc 仅回退拖动，不丢失刚确认的数值。
- 自定义工作台使用带尺寸、颜色与预览的表单对话框，替换串行 prompt；保留已有本地自定义库格式，未扩展到 G5 目录维护功能。
- 记住视图、左右面板、设备库/对象列表页签、分屏比例及方向、3D 俯视/斜视和移动开关。偏好与项目正文分离；三维默认关闭移动，按钮明确显示开关状态。
- 三维选中态落在物体外包轮廓上，支持共同选择和组拖动；提供俯视、斜视、全景、特写及复位。区域从 2D/列表选中时也显示范围线。
- 主要属性标签为 13px、输入为 14px；工具栏可换行。拆出对象列表、批量/单选属性、自定义表单、快捷键和工作台偏好，未引入通用命令框架。
