**实现与使用**

- 多边形功能分区：在“设备布置”点击“多边形分区”，逐点绘制凹形轮廓后闭合。选中分区可改名称、颜色、位置、尺寸和旋转；“编辑分区顶点”支持拖动、点击边中点加点、右键顶点删点。绘制时 Backspace 回退上一点，Esc 取消；完成的改动可撤销。矩形分区和原有矩形分割保留，多边形不套用矩形分割。
- 面积统计：各区面积之和、去重覆盖面积、重叠覆盖面积分别显示。均仅计算整场地内的部分；重叠覆盖指至少被两个分区覆盖，多重重叠只计一次，并不是“面积之和减去覆盖面积”。编辑器包含隐藏分区并明示口径；已有客户成果只统计可见分区。场地总面积始终单独计算。
- 2D/3D 使用同一多边形边界。二维按场地裁切，三维将场地与分区三角剖分后求交显示，支持凹形边界和多个不连通的相交部分；导出保留真实分区形状。统计采用边交点分段的精确线性积分，不用栅格近似。
- “现场设施”目录新增矩形柱体、固定设施、工程点位。点位可选择入口、排烟、上水、下水、电力，2D/3D 有对应标记；可填写“已确认 / 待核实”和备注。点位尺寸控制标记大小，不代表工程设备规格。固定设施沿用锁定、显隐、对象列表和规划范围外保护。
- 开启吸附时，新画墙的两端、已有墙端点可吸附到现有可见墙端点，画布显示“墙端点”提示。优先精确端点，其次网格；Alt 同时临时关闭两者。参照墙可以锁定，但不会被移动。普通墙整体拖动仍保持原有网格方式，不扩展 G4 的边缘/中心吸附。
- 常见同高双墙转角共用斜接轮廓，2D 去掉接缝内边线，3D 按相同截面生成墙端。墙中心线、逻辑长度、门窗偏移和世界坐标保持不变。移动到不再相接的位置后，显示截面自动恢复；撤销后连接也恢复。

**数据与轻量边界**

当前项目格式为 **4**，读取未标版本及版本 1/2/3；未知未来版本拒绝。项目包格式仍为 1，继续携带 IndexedDB 底图资产。普通 JSON 的“不含图片”规则不变。

分区在 Item 中增加归一化局部 `polygon` 顶点，由位置/尺寸/旋转转换到世界坐标，因而复制、移动和旋转不需要额外同步第二套坐标。轮廓要求简单闭合、3–64 顶点、不自交，最小面积 0.01㎡；不支持带洞分区。现场对象增加 `column` / `fixture` / `utility`，保存点位类型、确认状态与备注。墙端连接截面实时派生，不另外保存拓扑或引入布尔建模系统。

转角修整限定两个可见墙端、同高、非共线且不过度尖锐的交角；斜接延伸不超过较厚墙厚的 4 倍，端部必须有足够实墙空间。多墙交汇、不同墙高、过小角度、端部开口过近等退回原截面，保留合法墙窗。此阶段不是施工级 CAD：无自动机电系统、工程合规结论、任意洞口布尔或多楼层。
