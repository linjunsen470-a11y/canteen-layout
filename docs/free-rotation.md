**所有设备与空间构件自由旋转**

2026-11-05，用户追加需求已完成，保留此前本地功能和未提交修改。

选中任意可编辑对象，拖动二维画布上的 ↻ 圆形手柄，围绕对象中心自由旋转。手柄显示角度，默认精度 0.1°，不受网格吸附开关影响；按 Shift 临时吸附 15°。侧栏统一的“旋转角度（°）”支持精确数值、小数、负数及超过一周的输入，显示归一化为 0–360°。手柄获焦后左右键微转 1°，Shift 为 15°，Home 回到 0°。

一次拖动只记一次撤销；Esc、失焦、工具或视图切换取消当前旋转。旋转时暂停画布滚轮缩放，避免坐标变化造成跳转。锁定、隐藏、规划范围外保护继续生效，需要先解锁或切回整场地。分区、标注同样支持旋转；圆桌等旋转对称外形可能看不出轮廓变化，但角度仍被保存。

门窗有两种明确行为：

- 旋转墙体：原有关联门窗随墙移动和旋转，保留开口。
- 单独旋转门窗：保持自身中心，转为独立放置，清除墙体关联及原开口。可自由移动、旋转、复制，窗台高度保留；在“所属墙体”选择墙可重新贴墙、恢复沿墙方向与开口。无可用墙时从目录添加门窗会独立放置。

批量角度修改围绕各自中心，不视作组合旋转；同时选中墙及其门窗时只改墙角度并带动门窗，避免重复旋转。平面导出不包含旋转柄，3D 使用同一角度数据。

项目格式为 5，增加门窗 `freeStanding` 标记；读取旧文件和版本 1–4，避免旧版静默丢失独立门窗状态。项目包格式不变。没有新增依赖或云端服务，没有推进 G4 其他条目。

**实际验收**

在 Windows Chrome 156.0.8078.80、1366×768 的隔离浏览器中，使用已完成 G3 的合成项目包走了一条实际鼠标/键盘操作流程，24 项检查通过，页面异常 0。

- 鼠标将桌子旋转 37.4°：中心不变，一次拖动仅一个历史记录；Esc 恢复且释放手势。
- 输入 361.25° 得到 1.25°，输入 −17.5° 得到 342.5°；拖动跨越 359°→3° 正常；Shift 才按 15° 吸附；撤销/重做正确。
