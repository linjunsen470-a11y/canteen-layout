# 第五轮：画图优先的界面精简

日期：2026-11-06。针对默认界面按钮和信息偏多、难以专注画图的反馈实施。沿用已有未提交成果，仅修改本仓库；未提交、推送、部署或访问生产数据。

## 使用变化

- 顶部保留项目、保存状态、撤销／重做和保存。**文件与导出**集中提供 JSON、项目包、导入、PNG 和客户成果；执行后收起菜单。
- 设备／建筑模式下，没有选中对象时右侧面板让出画布。选择设备后显示属性；**场地设置**明确打开场地资料。手动收起属性的偏好仍保留，不会因添加设备强制展开。
- 绘图工具改为紧凑工具条。**分区与标注**提供矩形／多边形分区和三种标注，**选中操作**提供复制、副本、锁定、对齐、等距和删除，**排列与检查**保留组合、阵列、净距标注和 900mm 参考检查。
- **画布设置**集中网格、吸附、间距和操作提示。菜单浮出显示，打开不会改变画布尺寸；点击外部或 Esc 收起。正在画图时仍显示当前工具和退出入口。
- 设备卡片默认只负责选择和添加。点 **管理规格**后显示另存、编辑、复制和删除；**完成管理**回到简洁目录。实例的另存入口在属性的 **设备规格与来源**内。搜索、分类、67 个内置条目和自定义库均保留。
- 单视图不再重复显示“2D／3D”标题；分屏保留视图标题。收起默认分区统计、规格来源详情，移走常驻的通用操作说明。错误、保存状态、离墙预览状态、当前规划范围及保护入口仍可见。
- 专注状态下点 **场地资料 / 范围**会恢复属性面板，可直接调整范围设置；不改变对象锁定和保护语义。

## 实现与兼容性

新增 `EditorToolbar.tsx` 承接工具入口，`ToolMenu.tsx` 使用浏览器原生 Popover 顶层显示，支持外部点击、键盘退出、打开时的窗口缩放和受限高度滚动。没有增加依赖。

菜单打开时画布快捷键暂停，输入框维持原生编辑行为。数字输入的 Esc 仍丢弃草稿。导入改为可键盘操作的按钮。客户成果对话框挂载到页面顶层，避免父菜单收起时连同对话框一起隐藏；对话框的 Esc 与菜单退出分别处理。

属性面板的显示根据选择／模式计算，没有改写用户的面板开关与宽度偏好。没有新增项目、目录或持久化字段，项目格式仍为 6。设备规格、墙体关联、门向、分组、规划保护、历史和资产包逻辑沿用原实现。

| 1366×768 | 766×423 | 1060×556 | 约 82% |

选中设备、两侧栏都显示时，1366 窗口画布为 766×556，1024 窗口为约 427.53×473。800×600 也检查了按钮、菜单滚动和页面横向溢出；更窄窗口仍可收起侧栏或进入专注模式。
