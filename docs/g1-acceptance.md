# G1 多项目与数据安全：实现与验收

日期：2026-11-05。范围：仅当前仓库、本地浏览器，使用明确的合成项目；未连接云端、业务库或线上环境。现有未提交文件保留，未执行 reset、clean 或提交。

## 交付内容

- 项目库支持空白新建、打开、重命名、命名副本、明确的示例入口、删除及回收站恢复。删除当前项目前需先打开其他项目。
- 文件版本 1：稳定项目 ID、创建/修改时间、客户、场地、用途、需求备注；房源/咨询 ID 为可选字段，尚无业务接入界面。
- IndexedDB 保存完整项目快照。每个项目保留当前工作草稿及上一份成功保存；恢复记录以新项目打开。命名副本使用新 ID，后续编辑互不影响。
- 450ms 合并保存，拖动事务中不写盘，结束后保存。顶部持续显示未保存、保存中、已保存、失败或冲突；切换前等待当前保存完成。
- 写入与 expectedRevision 校验、恢复副本更新在同一事务完成。失败不替换成功记录，保留内存、可重试/导出；跨标签页广播提示冲突，事务校验不依赖广播。
- 旧 localStorage 一次性迁入并核对项目和标记，原键原文保留。无版本 JSON 升级，矩形及不规则轮廓保留；未来版本明确拒绝。文件导入以新项目 ID 保存，避免覆盖已有记录。
- 新增项目管理对话框使用原生焦点约束；后台编辑快捷键在对话框开启时暂停。项目切换重置画布临时工具，保存不清空选择和撤销历史。
- 预留 IndexedDB assets store，未提前实现 G3 图片入口或资产管理。

## 保留的必要回归

`tests/g1-storage.browser.js` 是小规模浏览器回归函数，使用真实 IndexedDB、store 编辑事务和故障注入，不增加测试依赖。

在**新启动的 Vite 服务、一次性隔离浏览器上下文**中打开应用后，在开发者控制台运行：

```js
await (await import('/tests/g1-storage.browser.js')).default()
```

函数创建合成项目并返回检查结果；不要在日常使用的浏览器项目库运行。启动迁移、双标签页广播和真实画布拖动按上表流程单独验收。测试服务启动后不要热修改存储模块，以免开发态的版本化模块 URL 干扰动态导入。

## 已知边界与下一入口

- 项目库属于当前浏览器配置及 origin（含端口），清除站点数据会一并清除项目和恢复记录；JSON 仍需定期另存作为外部备份。
- 仅保留一份前次成功快照，不是长期历史版本；命名副本为独立项目。未完成拖动与强制退出前尚未落盘的编辑不保证恢复；普通离开页面会提示未保存并尽力提交。
- 写入失败使用注入验证；尚未验证真实磁盘耗尽、浏览器崩溃及全部浏览器兼容性，不据此宣称商业发布完成。
- 不自动合并冲突；保留内存后另存副本，再打开最新项目。恢复当前项目之前的快照也总是新建记录。
