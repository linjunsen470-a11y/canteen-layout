# 三维空格拖动平移

日期：2026-11-06。按用户要求补充类似 CAD 的临时平移操作，沿用现有工作区和未提交成果。

## 使用

鼠标移到三维画布，按住 **空格＋鼠标左键拖动**，同时移动相机和观察中心。保持观察角度及距离不变，之后可继续围绕新中心旋转或缩放。按住时显示抓手，拖动时显示抓取状态，不增加常驻按钮。

松开空格后，下一次左键拖动恢复旋转，或恢复已开启的设备移动功能。若在本次拖动中先松开空格，本次仍作为平移完成，鼠标抬起后恢复，避免手势突然跳成旋转。

- 开启设备移动时，也可以从设备上空格拖动视图，不移动设备或改变选择。
- 原右键平移、滚轮缩放继续保留。临时平移无惯性；普通旋转的阻尼设置在结束后恢复。
- 文本输入中的空格和按钮的键盘激活保留。打开对话框／工具菜单时不抢键盘操作。
- 区域框选优先，先完成或取消框选再平移；已经开始的设备拖动不在半途切换为平移。
- 切离三维、窗口失焦或页面隐藏时清理临时状态。相机调整不写项目或撤销历史，不新增项目字段。
