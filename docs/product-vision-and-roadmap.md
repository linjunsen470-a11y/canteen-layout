# 餐饮铺位规划与开发方向

老板量完铺位后，应能看到后厨面积、前厅可摆桌数和最窄处的实际距离。导出的平面图使用项目中实际摆入的物件。示范案例在独立页签中打开，供参考装修风格与桌型。

## 当前工作流程

1. 录入净宽和净深，或逐段录入直角墙长（支持一键自动闭合）。门窗、承重柱、排烟井、给排水和顾客入口均可按内墙角量距定位，内凹角自动显示可用的洞口范围。
2. 新建毛坯铺位后，2D 画布顶部提供自动隐藏的 3 步快建条（放临街大门 / 智能分区估算 / 暖调 3D 分屏）；选中桌椅或门窗时浮出快捷操作条（左/右转 90°、快捷键 `R`/`Shift+R`、翻开向、四向按净距复制、副本与删除）。
3. 打开「智能分区估算」选择业态、后厨方向与面积占比，可选加明档半高隔断或在无大门时示意临街玻璃门窗。拖动占比滑杆看目标值，松开后更新平面。斜边轮廓使用手动布置。
4. 按选择的桌间净距试排。预览标出不同桌椅组之间的最短边缘距离，包含椅背。厨房沿墙尝试其他空位，未摆入的设备列在预览中。采购按已摆物件估算，配电另计每平方米 0.04 kW 的场地基础负荷。
5. 3D 鸟瞰默认开启「智能透视墙」（旋转视角时自动降低挡住视线的近侧外墙，后侧墙保持全高），切至「门头外观 / 人视点进店」自动恢复全高墙；支持对比原图、整体撤销或另存独立方案。PNG 只标用户指定的入口。

桌间距表示家具占地之间的几何距离。店主仍需单独核对出餐路线、顾客从入口到座位的路线及当地要求。

## 可借鉴的开源设计

| 功能 | 已借鉴 / 后续可借鉴的做法 | 项目 |
| --- | --- | --- |
| 贴墙与智能透视墙 | 独立/靠墙/嵌墙分类，以及 3D 鸟瞰面向相机外墙自动降高（已落地） | [Blueprint3D](https://github.com/furnishup/blueprint3d) |
| 2D 与 3D 的物件规格 | 让两个视图使用同一份物件尺寸与朝向 | [React Planner](https://github.com/cvdlab/react-planner) |
| 编辑与预览 | 非破坏性试排预览、快捷旋转 `R`、视角切换与清晰量距反馈 | [Pascal Editor](https://github.com/pascalorg/editor) · [Floorplan 3D](https://github.com/wy51ai/floorplan-3d) |

其他交互参考见 [House Planner](https://github.com/egmalt/house-planner)、[openPlan3D](https://github.com/laanlabs/openPlan3D)、[OpenCalque](https://github.com/laurent512/opencalque) 和 [Archlang](https://github.com/ChanMeng666/archlang)。

## 下一步

1. **局部试排。** 让店主在画布上框选一块空白区域，只针对该区域试排桌型和调节净距，完全保留其他区域已有布置。
2. **3D 分区快速飞入。** 点击功能区标签（后厨 / 水吧 / 客区），3D 镜头平滑飞入局部审视。
3. **2D 智能对齐吸附标尺。** 拖动桌椅时实时显示与相邻桌椅的动态间距毫米标尺，减少手动复核步骤。
