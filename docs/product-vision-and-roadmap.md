# 餐饮铺位规划与开发方向

老板量完铺位后，应能看到后厨面积、前厅可摆桌数和最窄处的实际距离。导出的平面图使用项目中实际摆入的物件。示范案例在独立页签中打开，供参考装修风格与桌型。

## 当前工作流程

1. 录入净宽和净深，或逐段录入直角墙长（支持一键自动闭合）。门窗、承重柱、排烟井、给排水和顾客入口均可按内墙角量距定位，内凹角自动显示可用的洞口范围。
2. 新建毛坯铺位后，2D 画布顶部提供自动隐藏的 3 步快建条（放临街大门 / 智能分区估算 / 暖调 3D 分屏）；选中桌椅或门窗时浮出快捷操作条（左/右转 90°、快捷键 `R`/`Shift+R`、翻开向、四向按净距复制、副本与删除）。
3. 打开「智能分区估算」选择业态、后厨方向与面积占比，可选加明档半高隔断或在无大门时示意临街玻璃门窗。拖动占比滑杆看目标值，松开后更新平面。斜边轮廓使用手动布置。
4. 按选择的桌间净距试排。预览标出不同桌椅组之间的最短边缘距离，包含椅背。厨房沿墙尝试其他空位，未摆入的设备列在预览中。采购按已摆物件估算，配电另计每平方米 0.04 kW 的场地基础负荷。
5. 3D 鸟瞰默认开启「智能透视墙」（旋转视角时自动降低挡住视线的近侧外墙，后侧墙保持全高），切至「门头外观 / 人视点进店」自动恢复全高墙；支持对比原图、整体撤销或另存独立方案。PNG 只标用户指定的入口。

桌间距表示家具占地之间的几何距离。店主仍需单独核对出餐路线、顾客从入口到座位的路线及当地要求。

### 已约定的行为规则（后续改动请勿破坏）

- **示意构件可重排**：智能分区生成的临街门窗、明档隔断带 `generated: 'concept'` 标记，再次试排时会被清除并按新参数重新生成，不会变成固定障碍；店主锁定后即视为实测构件永久保留。
- **吊灯不抢点击**：2D 中吊灯中心落在桌椅等落地物件上时自动“点击穿透”，点桌子选中的是桌子；空地上的灯、已选中的灯仍可直接操作，也可框选或在清单中选择。
- **门窗不越过实测墙角**：快建“放临街大门”和智能分区示意门窗都通过 `openingSlot(..., bounds)` 限制在 `surveyWall()` 给出的实测内墙可用范围内。

## 下一步：以画布为中心的三步架构

当前界面问题的根因是“功能叠加”：画布周围堆了 6 层横条（顶栏 / 编辑标题 / 工具栏 / 2D 快捷条 / 2D 底部工具 / 状态栏），左栏筛选区约 270px，右栏把日常操作和工程参数平铺，核心试排依赖弹窗。下一阶段只做减法与画布内直接操作，**不扩展合伙人方案书等外围功能**。

### 目标布局

```
┌ 顶栏一行：店名 | ①铺位 ②布局 ③效果 | 撤销/重做 | 导出 ┐
│ 左：图标栏 + 可收起抽屉 │        画布（2D / 3D / 分屏）        │ 右：选中时才出现的属性卡 │
│ （套餐 / 单品 / 清单）  │  画布内悬浮：视角胶囊、缩放、吸附    │                          │
└ 底部：开店指标条（净面积 · 座位 · 餐厨比 · ⚠瓶颈），点击展开 ┘
```

- 顶栏中间的“①铺位 ②布局 ③效果”既是导航，也决定左栏内容和可用工具。
- 左栏：分类改为搜索框下的一行横向标签；套餐卡片直接可见。
- 右栏按需展开：默认只显示尺寸 / 颜色 / 旋转 / 复制；坐标、离墙定位、规格来源、归属区等收进「精确尺寸与工程参数」。
- 3D 视角与光线收进一个悬浮胶囊，不再占两行工具栏；出图视角隐藏选中框。

### 三步流程

1. **①铺位**：录内净尺寸或 L 形；直接点外墙弹出“加门 / 加窗 / 量距”，点墙角放柱子与上下水、排烟，不再经过对象列表与折叠面板。
2. **②布局（核心）**：
   - **可拖动餐厨分界线**：2D 中直接拖，两侧实时显示 `后厨 24.5㎡ (32%)` / `前厅 52.0㎡ · 可摆 36 座`，松手只重排 `generated` 物件。智能分区弹窗降级为首次一键生成入口。
   - **框选生成桌阵**：框出区域 → 悬浮条选桌型（卡座 / 4 人 / 2 人 / 长桌）与净距滑杆，实时显示座位数；松手后每张桌可单独调整，其他区域完全保留。
   - 吊灯独立为灯光层。
3. **③效果与算账**：3D 默认智能透视墙；2D 选中功能区，3D 镜头平滑飞入；底部指标条显示净面积、总座位、餐厨比、单位面积座位数与瓶颈（最窄通道 < 900mm、缺排烟 / 洗消、灶具需 380V），点击瓶颈定位到画布位置；导出 A/B 两种摆法对比图。

### 技术架构

- 将 `PlanEditor.tsx` 按图层拆为 `ShellLayer` / `ZoneLayer` / `FurnitureLayer` / `LightLayer` / `OverlayLayer`，每层独立控制命中。
- 统一安装方式字段（Blueprint3D）：`in-wall` / `wall-floor` / `floor` / `ceiling`，吸附、命中、3D 透视由数据驱动，替代零散的 `modelOf` 判断。
- 布局引擎保持纯函数 `generateConceptLayout(shell, constraints, params)`；分界线与桌阵只是不同参数，便于实时重算与测试。
- 继续以整数毫米 `survey` + `parseProject` 作为唯一数据来源。
