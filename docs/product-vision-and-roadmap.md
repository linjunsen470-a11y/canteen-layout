# 餐饮铺位规划与开发方向

老板量完铺位后，应能看到后厨面积、前厅可摆桌数和最窄处的实际距离。导出的平面图使用项目中实际摆入的物件。示范案例在独立页签中打开，供参考装修风格与桌型。

## 当前工作流程

1. 录入净宽和净深，或逐段录入直角墙长。门窗按内墙角定位，内凹角显示可用的洞口范围。
2. 标明入口，放置墙、隔断、柱子、楼梯和现场点位。试排保留这些对象、底图和实测记录。
3. 选择业态、后厨方向与面积占比。拖动占比滑杆时可以看目标值，松开后更新平面。斜边轮廓使用手动布置。
4. 按选择的桌间净距试排。预览标出不同桌椅组之间的最短边缘距离，包含椅背。厨房沿墙尝试其他空位，未摆入的设备列在预览中。采购按已摆物件估算，配电另计每平方米 0.04 kW 的场地基础负荷。
5. 对比原图，查看将替换的分区和物件。应用可整体撤销，另存可独立编辑。PNG 只标用户指定的入口。

桌间距表示家具占地之间的几何距离。店主仍需单独核对出餐路线、顾客从入口到座位的路线及当地要求。

## 可借鉴的开源设计

| 功能 | 后续可借鉴的做法 | 项目 |
| --- | --- | --- |
| 贴墙与嵌墙设备 | 将独立摆放、靠墙摆放、嵌墙门窗分别处理 | [Blueprint3D](https://github.com/furnishup/blueprint3d) |
| 2D 与 3D 的物件规格 | 让两个视图使用同一份物件尺寸与朝向 | [React Planner](https://github.com/cvdlab/react-planner) |
| 编辑与预览 | 参考三维编辑器的视角切换、选择反馈和量距交互 | [Pascal Editor](https://github.com/pascalorg/editor) · [Floorplan 3D](https://github.com/wy51ai/floorplan-3d) |

其他交互参考见 [House Planner](https://github.com/egmalt/house-planner)、[openPlan3D](https://github.com/laanlabs/openPlan3D)、[OpenCalque](https://github.com/laurent512/opencalque) 和 [Archlang](https://github.com/ChanMeng666/archlang)。

## 下一步

1. **现场定位。** 将墙角量距扩展到柱子、排烟井和给排水点，让店主能复核固定构件位置。
2. **局部试排。** 让店主选一块空白区域调整桌型和净距，保留已经确认的布局。
3. **同铺位方案交付。** 将两张平面、座数、最窄桌间距和缺失设备放进一份对比报告。窄铺的三维视角和复尺交底表可在此基础上补充。
