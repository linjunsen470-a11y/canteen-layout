# 第一轮体验升级与验收

日期：2026-11-05。范围：设备二维朝向、单设备精确离墙定位、工作台空间减负。保留本轮开始时所有未提交成果；没有 reset、clean、提交、推送、部署，也没有访问招商仓库或生产数据。这不是 G5 整阶段完成或正式商用发布。

## 使用方式

1. 从设备库添加常用设备。绿色粗边表示正面／操作边；炉头、水槽、柜门把手、背板、椅背用于辨认设备。自助取餐台的蓝色双线是对客侧。旋转角度或旋转柄同时改变设备和图例方向。
2. 单选普通矩形设备，在属性顶部点 **精确离墙定位**。明确选择墙体及 A/B 面；橙色墙面和法向指示参考，粉色设备边／角点表示测量端。不会自动换墙面。
3. 输入毫米数值，点 **预览移动**。虚线位置尚未进入方案。点 **确认落位**提交一次可撤销移动；取消或 Esc 保留原位置。0 表示接触墙面，仍检查实际穿透。输入期间的全选、删除、复制是文本操作。
4. 自定义设备默认没有操作面；旧项目缺字段也默认不显示。模型有明确正面时，可在 **操作面显示**中主动确认，也可再次关闭。
5. 没有选择对象时收起无用的复制／锁定／对齐等操作；设备库优先餐饮、厨房、热厨、洗消、餐桌椅。全部 67 个条目、搜索和分类仍保留。侧栏调宽、工具折叠与 F 专注模式继续可用。
6. 规划范围详细设置默认折叠；已有范围时，范围选择和保护开关独立于折叠工具区，专注模式也能切回整场地。退出范围不会改变用户对象锁定。

## 实现与数据约定

- 8 类共享符号：炉灶、水池（单／双／三槽共用）、立式冰箱、蒸饭柜、消毒柜、工作台、自助取餐台、餐椅。不添加重复目录条目或厂家参数。
- 冻结的 `equipmentFacing.ts` v1 映射使用 `model`，不以可修改的名称判断朝向。正面是设备中心坐标的二维 **+Y**，对应 Three.js **+Z**；二维顺时针角度对应三维绕 Y 的负角度。已检查炉灶控制件、柜门把手、池背板、椅背和售卖台挡板的实际模型结构。工作台补充后侧横挡以统一约定；仍为通用示意模型。
- `EquipmentSymbol.tsx` 在编辑器与属性图例中复用，缩略图和三维仍共用 `createFurniture`。编辑器小于 16px 的短边简化细节，保留操作边；导出按输出比例重新决定细节显隐，保留操作边颜色与椅背厚度。名称移到符号外侧，预览与测量覆盖层不导出。
- 可选的 `Item.operationFace` 属于**项目实例**，值为 `positive-y` 或 `none`；内置新设备按已核对模型初始化，自定义新设备为 `none`。导入缺字段时统一用 `none`，不猜历史自定义设备。首次初始化后保存明确值；目录或名称变化不重新推断。
- 这是附加显示元数据，没有改变几何、引用或资产结构，**项目格式继续为 6，资产包继续为 1**。解析器逐字段保留并校验新值，仍接受无版本和 1–5。旧版应用不理解该显示字段，不应拿旧程序往返编辑新显示设置；几何、门向及原有关系没有格式迁移。
- 净距使用旋转矩形顶点与所选墙面法向的支撑距离；参考是墙厚外表面，端部取现有 `wallProfiles` 的实际修角轮廓。目标位移仅为法向乘以距离差，不沿墙滑动、不改角度。设备完整切向投影必须落在墙面段内，投影经过门窗开口时拒绝作为连续实体墙面。
- 定位会话在独立 Zustand 状态中，不修改 Project、不触发预览自动保存、不写历史；确认重新验证后复用 `store.update`。修改项目内容、选择或范围会取消旧会话；自动保存仅更新时间不会取消。输入修改会清除旧预览，不能确认过期数值。
- 原始位置、目标位置都检查范围保护；组合成员、显式或自动承托关系禁用。目标完整轮廓检查场地边界及实体重叠，包含隐藏实体，未关闭碰撞检查。投影数值误差容忍 0.01mm，碰撞复用面积算法的 1mm² 容差。原有默认 **900mm 参考净距提示完整保留**，不是按设备制定了新的安装间距规则。

主要实现：`equipmentFacing.ts`、`EquipmentSymbol.tsx`、`wallClearance.ts`、`wallPlacement.ts`、`WallClearanceFields.tsx`、`WallClearanceOverlay.tsx`；接入现有导入、校验、编辑器、属性、导出和键盘处理。无新增依赖或框架重构。

### 过程中发现的问题

- 新状态行曾挤压 800×600 专注视图；改为仅非选择工具显示退出条，选择状态沿用原底栏。复跑 66 项全部通过，未降低断言要求。
- 自动保存仅更新时间曾使定位会话失效；现比较实际内容变化，新增等待自动保存后预览仍在的断言。
- 新验收脚本初稿直接替换项目身份导致测试会话修订冲突，已改为保留活动项目身份；导入等待也改为等待目标对象实际渲染，不把等待中状态当作导入完成。
- G4 原脚本未指定下载目录，遇到 Chrome `download.saveAs: canceled`；指定本轮目录后 33 项通过。属于验收环境／脚本问题，不宣称为产品几何回归。
- 原有构建包体积提示仍存在，未删检查或屏蔽提示。

## 边界与后续

仅处理一个矩形占地普通设备与显式选择的墙体长侧面。圆桌的既有 48 边近似不用于本功能；圆桌、墙端面、局部投影、墙体开口、组合整体和承托关联移动均留待后续。参照墙面可以是锁定建筑背景，但设备本身必须可编辑；范围保护与用户锁定独立。

定位是终点落位检查，不是搬运过程的连续碰撞路径求解；二维外包轮廓也不是厂家实体细节。极低缩放会简化符号，应放大或定位查看。既有 900mm 检查仍只是业务参考，不提供施工或合规结论。尚未验证手机触控、其他浏览器／显卡组合、真实客户场地和操作者试点；没有运行无关性能压力测试。

没有扩展机电／排烟、供餐推算、动线、模板、GLB、云保存、分享、小程序、CSV 或完整打印交付系统。本轮到此结束，后续仍按路线图的未完成事项另行启动。
