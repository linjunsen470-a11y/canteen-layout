# G4 布局效率、标注与空间检查

日期：2026-11-05。状态：本地 G4 已实现并完成实际操作验收。保留既有 2D/3D、自由旋转、底图、资产包、规划范围、功能分区及未提交修改；未进入 G5 或云端。

## 使用与数据规则

工作台的“布局工具”提供组合、整体旋转、重复布置、复制落位、关联净距和空间检查。单件 ↻ 自由旋转及右侧任意角度输入保持原有行为。

| 能力 | 本轮行为 |
| --- | --- |
| 组合与解组 | 成员仍是独立对象，组合/解组不改变成员 ID；单击选整组，双击或 Ctrl 单击选单件，Ctrl+Shift 逐个增减。墙体组合包括附属门窗。 |
| 整体旋转 | 围绕选择外包中心旋转，保持成员相对距离和朝向差；区别于批量属性的“统一朝向”。 |
| 行列重复 | 行列包含原件，默认 2×3；间距为世界坐标 X/Y 位移，一次最多 100 组。副本 ID 独立，整批一次撤销。贴墙门窗需连墙重复，或先转为独立放置。 |
| 复制后放置 | 指针预览、点击落位、Esc 回滚；预览中不写自动保存，完成后一次历史记录。 |
| 微移与吸附 | 方向键 10mm、Shift 100mm、Alt 1mm；几何吸附与网格分别开关，Alt 临时关闭。墙边/端点及物体边缘/中心提供参考线。 |
| 对齐/分布 | 左对齐、水平等距使用旋转轮廓外界；完整组选为一个单元。尊重锁定、隐藏、墙窗关系及规划保护；整组有不可编辑成员时拒绝部分变换。 |
| 关联净距 | 选两个物件/墙体量取轮廓最短距离，交叠时为 0；端点移动、旋转、尺寸变化后同步更新，可修改文字、偏移、字号和颜色。删除端点时移除标注，撤销一起恢复。 |
| 空间检查 | 可见物件完整旋转轮廓与场地/当前规划范围比较；区分固定障碍、一般重叠、门扇开启和参考净距。点击提示收起面板并定位，编辑后结果标为待重查。 |
| 座位统计 | 以可见对象显式 `seats` 累加；组合 `seats` 替代成员计数。默认餐椅/凳声明 1，四人桌椅预置为桌 0、四椅各 1。隐藏不计，未声明座椅及声明组合部分隐藏提示待确认，不解析名称。 |
| 合理叠放 | 咖啡机、微波炉、电饭煲、饮料机完整位于有效桌面时自动识别；非承托类设备也可明确选择承托物。3D 和检查使用桌面高度，设备移动仍独立；显式关系超出台面时提示调整。 |

项目格式升级为 **6**，新增组合、座位、关联净距、承托关系和参考净距；继续接受无版本及 1–5，未知未来版本拒绝。资产包版本仍为 1，无新应用依赖。

## 实际操作验收

使用本机 Chrome **156.0.8078.80** 的隔离存储，在本地开发服务上通过按钮、属性输入、真实鼠标拖动及键盘完成流程。初始几何为明确坐标的合成样例；读取运行时数据仅用于核对操作结果，没有通过直接改 store 冒充用户编辑。本次不是客户实测或合规审查。

- 从一组四人桌椅生成 6 组、30 个独立成员、24 座；整体 27.4° 旋转后相对距离不变，阵列一次撤销/重做。组合声明不重复计座，锁定组员不发生残缺移动。
- 三种步长微移、组内单件选择和 37.4° 鼠标自由旋转通过；复制预览 Esc 完整取消，点击落位一次提交/撤销，解组保留 ID。
- 30° 斜墙与 30° 设备得到 **500mm** 边界净距；拖动吸附墙边时为 0，并显示参考线；Alt 禁用后留下约 60mm。向右微移 10mm 后关联净距变为 **495mm**。
- 三件不同旋转设备左对齐后外界一致；水平分布后边缘间隔相等。完整轮廓超出规划范围的设备仍受范围外保护。
- 检查区分柱体碰撞、门扇范围及参考净距；场地/规划范围内的中心点不能掩盖旋转角越界。覆盖功能区与合理桌面咖啡机不误报，提示可定位。
- 删除测量端点同步移除标注，撤销恢复；本地保存、刷新和独立浏览器导入保持 G4 数据；六组/24 座随项目包迁移。
- 以既有 G3 包补查墙窗组合旋转、复制重映射和撤销；锁定门窗不会复制出残缺组合。原版本 4 底图包、版本 5 自由旋转包可导入格式 6，独立门窗状态保留。
- 浏览器页面异常为 0。主流程 **33 项**、关联补查 **7 项**通过；补查中修正了脚本异步导入的等待条件后重跑该片段，没有将未完成导入当作成功。
- `pnpm build` 通过；只做编译/构建与上述定向流程，未运行复杂全量测试或压力测试。仍有原有 Three/React 主包大于 500kB 的构建提示，本阶段未扩展为拆包优化。

复核脚本：[g4-workflow.cjs](../tests/g4-workflow.cjs)。传入本机 Playwright 模块路径运行主流程；追加 `linked` 仅执行墙窗/旧包补查。脚本启动本地临时服务和独立浏览器，退出时关闭，不使用用户浏览器数据。

## 轻量边界与下一步

- 检查为外轮廓/高度区间的业务提示，参考净距默认 900mm 可改，不判断消防、无障碍或其他规范合规。桌腿空隙、柜门细节、复杂工程管线、完整人流路径不模拟；圆/椭圆桌使用 48 段轮廓近似，门扇为示意扇形。墙体按外包截面检查，既有端点相接视为连接，不做三维实体布尔碰撞。
- “净距”是两轮廓的最短距离，不等同于整条通道的连续通行宽度；交叠显示 0。原有手绘尺寸保持手动记录，关联净距自动派生位置和角度，不能再独立拖走其测量端点。
- 组合为单层成员集合，解组后组合级容量声明消失，按成员明确值重新统计。旧项目没有座位声明时不擅自补容量；组合内部不报参考净距，但明显碰撞仍提示。
- 承托只服务于本阶段合理叠放检查和一致显示，不增加通用离地高度、嵌套承托或自动随台面移动；这些不替代 G5 的规格和模型质量工作。
- 本轮保留既有未提交修改，没有提交、重置、清理工作区或部署。下一阶段为 **G5 设备规格与模型质量**，需用户另行启动。
