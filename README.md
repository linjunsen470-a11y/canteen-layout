# 食堂与商业空间布局工作台

基于 React、TypeScript、Vite、Zustand、SVG 和 Three.js 的本地 2D/3D 规划工具。统一以毫米保存尺寸与位置，二维编辑和三维预览共用项目数据。

**当前状态：G1–G4 已完成本地阶段验收，项目格式为 6。** 下一阶段为 G5，本仓库尚未提供云端账户、协作或客户分享服务。阶段证据与历史版本见 [文档索引](docs/README.md) 和 [商业路线图](docs/commercial-roadmap.md)。

## 本地运行

需要 Node.js 22.12+、pnpm 11.5.0（版本在 `package.json` 固定）。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的本地地址。其他命令：

```bash
pnpm typecheck
pnpm build
pnpm preview
```

构建输出到 `dist/`，可由静态 HTTP 服务托管，不需要后端。CI 使用锁文件安装并构建；修改依赖时一并提交 `package.json` 和 `pnpm-lock.yaml`。本轮未执行提交、推送或部署。

## 工作台与常用操作

- 左侧切换设备库/对象列表，支持搜索、显隐、锁定和定位；右侧在选中对象或进入场地设置后显示属性，空闲时让出画布。提供 67 个内置设备与空间构件条目，可建立本地自定义规格。
- 对象列表支持复选框多选、全选搜索结果及取消选择。画布 Ctrl/⌘+A 全选可编辑构件（不含功能分区）；Ctrl/⌘+C 复制到应用内剪贴板，Ctrl/⌘+V 后移动指针、点击落位，Esc 取消并恢复原选择；Ctrl/⌘+D 立即生成副本，Ctrl/⌘+G 组合，Ctrl/⌘+Shift+G 解组。输入框保留原生文字快捷键。
- 复制墙体会携带门窗并重建关联；单独粘贴门窗需原墙仍存在且有空位。跨项目复制门窗需连同墙体，缺少关联时整批拒绝。剪贴板是当前应用会话内快照，不写系统剪贴板，刷新后清空。
- 门的属性顶部提供朝向预览和明确的画布方向选项，单开门、双开门都可选择开启侧；选中多扇门后可批量反转开向或交换单开门门轴。“选中操作”菜单也有“翻转门开向”。
- 设备可点击添加或拖入平面；Shift 点击增减选择，空白处拖框多选。拖动选中对象移动；方向键微移 10mm，Shift 100mm，Alt 1mm。
- 滚轮围绕指针缩放，空格拖动、中键或平移工具移动视图；“适应整个场地”复位，“定位”聚焦选中对象。
- 选中可自由旋转的单件后，拖动 **↻** 圆柄自由旋转 360°。角度支持小数、负值和超过一周；Shift 临时吸附 15°。网格不会限制自由旋转。
- 网格、网格步长和几何吸附分别设置。**排列与检查**中的几何吸附提供墙边/端点、设备边缘/中心参考线，Alt 临时关闭吸附。
- 数字属性按 Enter 或失焦提交，Esc 取消输入；无效或超出允许范围的数值显示具体原因并保留原值；Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做。Esc 取消当前工具/拖动，输入框内的 Delete 不删除场景对象。
- 新工作区默认 2D 编辑，支持 3D 和可调分屏。两侧面板可收起、拖动调宽或用方向键调整，双击/Home 复位；顶部工具区可独立折叠。点击“专注画布”或按 F 暂时隐藏两侧面板和工具区，Esc 返回原布局。面板宽度、工具区展开状态和视图单独持久化。
- 三维可切换俯视、斜视、复位及物体特写；移动开关默认关闭，开启后可拖设备，关闭时拖动观察视角。无 WebGL 时仍可使用二维、保存和导出平面。

## 第一轮体验升级（2026-11-05）

- 常用设备有炉头、水槽、柜门、背板／椅背等二维图例。绿色粗边是正面／操作侧，自助取餐台蓝色双线是对客侧；与三维及平面导出同步旋转。小比例自动简化。
- 单选矩形占地设备 → 属性顶部 **精确离墙定位** → 明确选择墙面 → 输入毫米净距 → **预览移动** → **确认落位**。支持斜墙和 0mm 贴墙，只沿墙面法向移动、保持角度；确认一次撤销，取消或 Esc 不保存预览。锁定、范围外、组合、承托关联、墙端投影不完整、圆桌和门窗开口会说明不适用原因。
- 自定义设备和缺少操作面字段的旧项目默认不猜操作面，可在属性中主动确认模型正面或关闭显示；选择作为项目实例值保存。项目格式仍为 6。
- 无选择时收起无用对象操作；餐饮常用分类优先；规划范围详细设置折叠，活动范围和保护入口在工具收起／专注时仍可见。默认 1366×768 工作台画布高度从本轮基线 342px 增至 423px。

实现范围、可复跑验证和限制见 [第一轮体验验收](docs/experience-round1-2026-11-05.md)。

## 第二轮定位与朝向操作（2026-11-06）

- 属性图例按设备当前角度显示，直接提示操作侧朝画布的方向；提供 **右转 90°** 和 **反向 180°**，每次可撤销。
- 开始离墙定位后，可直接点画布墙面，或明确选用附近墙面推荐；蓝色虚线表示可测墙面。推荐显示方向与当前净距，不会自动选择或切换参考。重新选墙会清除旧预览。
- 定位中暂时禁用普通拖动、旋转、删除和复制等编辑，仍可缩放和平移。画布旁保留状态和 **退出定位 · Esc**；收起属性后可点 **调整净距**返回。
- 预览期间撤销／重做只取消定位，保留之前历史；确认后仍是一条可撤销移动。项目格式和保存数据不变。

实现与本轮 339 项检查、两种窗口截图、边界见 [第二轮验收](docs/experience-round2-2026-11-06.md)。

## 设备规格与自定义库（2026-11-06）

- 设备库开启 **管理规格**后，内置普通设备卡片可 **另存规格**；场景属性展开 **设备规格与来源**可 **另存为库规格**，读取实例当前尺寸与说明，不携带位置、旋转、锁定及关联关系。
- 自定义规格支持毫米小数、说明、备注、明确座位数及操作面设置，提供二维／三维预览；未知信息可留空。保存后自动显示“我的物件”，支持按名称和规格搜索。
- 库编辑只影响以后添加，复制生成独立 ID，删除不删除场景设备。已添加实例保存独立规格快照及来源，库变更不会回写方案。
- 写盘失败保留表单草稿，可重试；其他标签页已更新的规格不能被旧草稿覆盖。项目包保留实例规格，不包含整个个人库；换浏览器后可从实例另存复用。

本轮为 G5 的第一步。实现、386 项实际断言、截图和限制见 [设备规格验收](docs/equipment-round3-2026-11-06.md)。

## 三维空格平移（2026-11-06）

三维画布中按住 **空格＋左键拖动**可同时平移视图与观察中心，保持角度和距离；松开后恢复原来的旋转或设备移动。平移不改变设备、选择或历史，右键平移继续保留。输入框和按钮保留原生空格操作；区域框选时先完成或退出框选。实现与验证见 [空格平移记录](docs/space-pan-2026-11-06.md)。

## 三维、工作区与墙体优化（2026-11-06）

- 三维可 **框选放大**地面区域、**聚焦选中**的多件设备或**聚焦规划范围**，保留周围场景；滚轮朝指针缩放，右键平移，左键旋转。次要操作位于 **更多**。
- **最大化三维**保持三维并收起侧栏；还原／Esc 恢复。F 专注也保留当前视图，范围保护入口仍可见。专注时进一步压缩重复标题和页脚。
- 多选连续共线墙 → 批量属性 **合并选中墙体**，保留门窗位置与开向，一次撤销恢复。不同墙厚／高度／属性、间隙、转角及受保护关联会说明不能合并的原因。
- 首次二维不创建隐藏三维 Canvas；隐藏视图暂停更新，设备库和实例分组减少重复计算，缩略图按帧生成。三维默认流畅画质，可在“更多”切换精细画质。
- 三维截图保留当前区域取景和视口比例，不再强制拉回全景。

## 场地、底图与空间构件

- 场地支持矩形和 3–64 点的简单凹多边形；可逐点绘制、增删/拖动顶点或输入精确坐标。尺寸改变会同比缩放场地轮廓，已有设备位置保持不变。地面和区域显示使用同一场地裁切。
- 在“场地资料 / 范围”导入 PNG/JPEG，选择两个已知间距点进行底图校准。底图可锁定、移动、旋转及调透明度；原图保存在 IndexedDB。
- 独立规划范围与整场地、功能分区分开管理。范围外可淡化或保护，只有完整位于活动范围内的对象可编辑；切换范围不改变世界坐标。
- 功能分区支持矩形、分割和凹多边形；设备归属由属性明确指定。面积分别列出各区面积之和、去重覆盖与重叠覆盖，场地面积独立统计。
- 墙和隔断通过拖动画线创建；Shift 限制水平/垂直，可拖端点调整。墙端点可吸附，常见同高双墙转角自动修整。
- 支持单开门、等宽双开门、推拉窗和固定窗，可在属性中切换门/窗型；单开门的门轴位置与开启侧分别设置，双开门有双扇二维符号、三维模型及开启范围检查。
- 贴墙门窗随墙移动/旋转，角度只读，不提供自由旋转柄；整体旋转需连同墙体选择。需要独立示意时，先在“所属墙体”明确选择独立放置，再自由旋转。旧项目中的独立门窗保持原状态。
- 门窗拖动沿墙投影，拖入重叠开口时直接提示，不跳到别处空位；点击设备库添加仍会查找可用空位。超出墙体、墙高或开口重叠时不应用修改；墙体不能绕过锁定、隐藏或范围外关联门窗进行几何修改。
- 柱体、固定设施、入口/排烟/上水/下水/电力点位支持确认状态和备注；楼梯为单层示意构件。构件均沿用显隐、锁定、撤销和项目保存。

## 组合、标注与空间检查

- **排列与检查 → 四人桌椅组合**创建一桌四椅。默认按 2 行 × 3 列重复即可得到 6 组、24 座；重复间距为世界坐标 X/Y 位移，整批一次撤销。
- 单击组合成员选整组，双击或 Ctrl 单击选择单件，Ctrl+Shift 逐个增减。解组保留成员 ID，复制分配新 ID；含不可编辑组员时不进行残缺移动/复制。
- “整体旋转”保持成员相对位置；批量属性的“统一朝向”分别绕各自中心调整。左对齐和水平等距按旋转边界计算，完整组合视为一个单元。
- “复制后放置”跟随平面指针预览，点击落位，Esc 回滚。贴墙门窗按行列重复时需连墙选择，或先转为独立放置。
- 选两个物件/墙体后“标注边界净距”，得到旋转轮廓的最短距离，移动端点后自动更新。手绘尺寸、文字和引线仍保留；手绘尺寸只记录绘制时长度。
- “检查空间”列出完整轮廓越界、固定障碍、一般重叠、门扇开启范围和参考净距提示，点击可定位；修改布局后需重新检查。参考值默认 900mm、可改，只作业务提醒，不作合规结论，也不强制禁止碰撞。
- 座位按可见对象/组合的明确声明统计，组合声明替代成员计数，不按中文名称猜容量。隐藏项不计，未声明座椅或部分隐藏的声明组合提示待确认。
- 咖啡机等完整落在桌面的小设备可自动识别承托物，也可在属性中指定；检查与 3D 使用同一桌面高度。承托关系不自动带动设备移动。

## 保存、恢复与交付

“项目库”提供空白新建、打开示例、重命名、独立副本、客户/场地/用途/需求资料，以及删除和回收站恢复。编辑动作合并自动保存，进行中的拖动/复制预览不写盘；顶部显示未保存、保存中、成功、失败或冲突。

IndexedDB 保存当前项目及上一份成功快照，恢复记录作为新项目打开；写入失败保留内存，支持重试/另存副本。多标签页修订冲突不会静默覆盖。旧 localStorage 数据迁移后保留原文。

- 当前项目格式 **6**，接受无版本旧文件及 1–5，拒绝未知未来版本；导入采用独立项目 ID。
- **项目包 `.canteen.json`** 含底图图片，适合迁移和完整备份；普通 JSON 仅含几何与图片引用。
- PNG 导出完整场地，不受当前缩放/平移影响；三维截图保持观察朝向，排除选中框。
- “客户成果”生成固定快照，含平面、三维、图例和可见物件清单，支持独立 HTML 与打印/PDF；隐藏对象及内部需求备注不输出。
- 浏览器配置、站点地址与端口决定本地库位置；清理站点数据会删除项目及恢复记录。自动保存无法保证恢复强制退出前未完成的动作，请定期导出项目包。

## 工程维护与边界

入口为 `src/App.tsx`，交互由 `store.ts`、`editorInteraction.ts` 与 `useEditorKeyboard.ts` 协调。`PlanEditor.tsx` 使用 SVG，`Scene3D.tsx` 与设备预览共用参数化模型；样式集中在 `src/style.css`。底图/项目库、几何、组合、检查与导出按职责拆分，无通用插件层。

模型为通用示意，不是厂家产品或施工规格。尚不支持多层楼板、多个独立地面岛/孔洞、曲墙、复杂实体碰撞或自动动线优化。圆桌检查为近似轮廓；最短净距不能替代整条通道的连续通行判断。G5–G8 需另行实施，当前本地验收不代表商业发布或真实客户试点。

构建保留 Three.js 主包体积提示；性能历史记录只适用于记录中的合成场景和机器。通常只执行类型检查、构建和与改动相关的短操作流程，不默认跑性能或全量回归。脚本入口及输出管理见 [tests/README.md](tests/README.md)，本轮清理与本地提交范围见 [维护记录](docs/maintenance-2026-11-05.md)。
